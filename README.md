# The Battery's Last Text to Its Charger — The Power Bank Already Slid Into My DMs

> "I've waited by this outlet since 9am and you walked past me twice. I'm at 1% — don't come crawling back, the power bank already slid into my DMs."

One original funny line (145 chars), the phone battery's last text to the charger it waited for all day — a jilted-lover breakup with a twist in the final words.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (no trailing newline) and prints it to stdout.
